# 代谢状态单细胞 RNA-seq Benchmark v0.1：构建与验收报告

生成日期：2026-09-11  
状态：第一阶段领域聚焦的 curation release 已完成；尚不是可计分 leaderboard release。

## 1. 研究边界

本数据集围绕固定代谢基因集在癌症单细胞 RNA-seq 中的三个问题组织：

1. 只用代谢基因，能否发现可重复、可跨样本验证的转录代谢状态？
2. 无监督得到的代谢状态是否与细胞类型相关，并且该相关性是否独立于患者、组织、批次、测序深度和线粒体比例？
3. 在同一细胞类型，尤其 CD8+ T 细胞内部，是否存在多个可重复的转录代谢状态？

这里的“代谢状态”默认仅指 RNA 支持的转录程序或模型推断的代谢潜能。若没有代谢组、同位素示踪、酶活性或其他正交证据，不能写成实测代谢通量或因果代谢机制。

## 3. 每篇论文的目录契约

每篇论文严格使用 `P###_author_year_short_title` 文件夹，并采用同一结构：

```text
papers/P###_.../
├── origin/
│   ├── main_article.pdf|xml|html
│   ├── supplementary/
│   ├── download_manifest.json
│   └── README.md
├── metadata/
│   ├── paper.json
│   └── bibliography.bib
├── data/
│   ├── data_manifest.json
│   └── README.md
├── task/public/
│   ├── task.yaml
│   ├── prompt.md
│   ├── data_manifest.public.json
│   ├── output_contract.schema.json
│   └── README.md
├── curation/
│   ├── paper_card.md
│   └── claim_map.jsonl
└── provenance/
    └── provenance.json
```

`task.yaml` 使用 JSON 兼容语法，因此同时满足 YAML 1.2 解析。正文和补充材料尽量保留出版社或 PMC 的原始文件名；统一的 `download_manifest.json` 保存角色、来源 URL、字节数和 SHA-256，不用伪造的占位 PDF 代替缺失材料。

| 推断 | 数量 |

1,727 个输入条目可给出推荐人类映射，去重后为 1,719 个候选人类符号。原 1,988 个输入仍保留；候选映射没有静默覆盖原始文件。

这意味着当前清单是明显的人/鼠混合符号集。如果分析对象是人类肿瘤 scRNA-seq，直接将原始大小写符号与 HGNC 矩阵取交集会造成严重特征丢失，并可能把技术性低覆盖误判为“没有代谢状态”。82 个 unresolved 条目和上游基因集来源/纳入规则，是进入正式评分前的阻断项。

相关文件：

- `genesets/metabolic_genes_hgnc_validation.tsv`：逐符号审计；
- `genesets/metabolic_genes_human_mapped_candidate_v1.csv`：候选人类映射；

符号有效不等于“该基因一定属于代谢”、也不证明该列表完整。正式版本还需补充原始生物学来源、代谢纳入规则、目标物种和版本策略。

## 6. 任务、数据、答案和轨迹的组织方式

### 6.1 Agent 可见任务

每篇论文有一条标准任务，公共注册表为 `registry/tasks_public.jsonl`。任务题干在 `task/public/task.yaml`，人类可读版本在 `prompt.md`，输出由 JSON Schema 约束。核心硬门槛包括：

- 报告基因符号和表达矩阵覆盖率；
- 以患者/供体/样本而不是细胞作为统计推断单位；
- 使用表达匹配的随机基因集负对照；
- 检查批次、组织、库大小和线粒体质量混杂；
- Q1/Q3 评估多随机种子和生物学重复抽样稳定性；
- 尽可能进行留出患者迁移；
- 不把 RNA 推断写成实测通量。

标准提交至少包括 `metrics.json`、`claims.jsonl`、`provenance.json` 和 `report.md`；Q1/Q3 另需 `cluster_assignments.tsv` 与 `state_summary.tsv`，Q2 另需 `associations.tsv`。指标契约支持 state count、ARI、留出 macro-F1、blocked permutation P 值、敏感性分析、不确定性和证据等级。

### 6.2 数据输入

每条任务都有 `data/data_manifest.json` 与 agent 可见的 `task/public/data_manifest.public.json`，记录数据集 ID、版本、accession、访问条件、应有的样本元数据字段和物化前检查项。

当前 30/30 条数据均为 `registered_not_materialized`：已定位到稳定标识和来源，但尚未把具体表达矩阵、细胞注释和患者/样本表下载、解包、统一并冻结哈希。因此当前任务全部 `scoreable: false`。这是一项实质边界，不能把文献与 accession 已收集等同于 benchmark 已可运行。

### 6.3 论文结论与答案隔离

论文正文、SI、paper card 和 candidate claim 均为 curator-only，不允许挂载到盲测 agent 环境。候选 rubric 和结论草稿进一步放在独立目录 `metabolic_scRNA_benchmark_v0.1_private/`。当前 private 目录 91 个文件均为草稿且非计分答案。

本地开发时，agent 只可访问：

1. 选定并冻结的数据快照；
2. `task/public/`；
3. 经 curator 明确批准的基因集版本。

完整 benchmark 根目录包含 curator-only 材料，因此未来对外发布时应制作独立 agent-visible 包，而不是直接把整个根目录交给被测模型。

### 6.4 运行轨迹

本阶段没有模型执行轨迹，也没有存储隐藏思维链。`runs/README.md` 规定后续每次运行保存：

```text
runs/<run_id>/
├── run.json
├── events.jsonl
├── human.log
├── workspace_manifest.json
├── submission/
└── grading/
```

其中 `events.jsonl` 只记录可观察动作、工具调用摘要、文件读写、时间、错误和重试；不要求也不应保存模型的私有 chain-of-thought。训练阶段应从可验证的工具轨迹、产物和显式 rationale/decision records 构造 SFT 数据。

## 7. 当前版本能做什么、不能做什么

### 已完成

- 30 篇高相关论文的统一登记、元数据、正文/SI 获取审计、哈希与目录标准化；
- 30 条结构化候选任务与输出格式；
- 30 条数据来源 manifest；
- 原始代谢基因集冻结及 HGNC/MGI 人鼠映射审计；
- agent 可见材料与 curator/private 材料的逻辑隔离；
- 可重复的构建器与严格验收命令。

### 尚未完成，因而不能宣称为 leaderboard

- 30 条任务的实际表达矩阵与临床/样本元数据尚未物化；
- 82 个基因符号尚未解决，上游代谢基因集来源未补齐；
- candidate claims 尚未由独立分析复现；
- 未完成 patient-level 敏感性、负对照与外部迁移；
- 未形成 sealed test、最终 gold、grader 对抗测试和双人签字；
- 尚无任何模型比较结果或运行轨迹。

## 8. 建议的下一准入门槛

不要立即扩充到 100–200 篇。先把最小的 8 条 pilot 做成可运行、可计分闭环：

| 目的 | 推荐条目 |
|---|---|
| Q1 代谢状态聚类 | P001、P002 |
| Q3 CD8+ T 内部状态 | P003、P004 |
| 代谢推断方法敏感性 | P014、P015 |
| 统计硬门槛 | P028、P029 |

推荐顺序：

1. 由领域专家裁定 82 个 unresolved 符号，确认原列表物种和来源，冻结 `human_v1`；
2. 选择一个最先可运行的数据集，下载具体矩阵、细胞注释、患者/样本表并逐文件哈希；
3. 在不看论文结论的 clean room 环境中执行 Q1–Q3；
4. 以患者为单位完成负对照、bootstrap、留出迁移和混杂诊断；
5. 独立 curator 根据复现结果重写 gold/rubric；
6. 做题干可回答性、数据泄漏和 grader 对抗测试；
7. 仅在通过双人签字后设置 `scoreable: true`；
8. 完成 8 条闭环后，再按同一规则扩到 100–200 篇。

## 9. 验收结论

v0.1 已达到“可审计的领域文献—任务—数据指针—候选答案隔离”的第一阶段 curation 基线，并且纠正了一个把 NCBI BioProject 页面误当作论文正文的语义错误。它没有达到“可直接让不同模型运行并产生 leaderboard”的标准。下一项决定性工作不是继续收集 PDF，而是解决基因物种映射并物化首个 pilot 的精确输入矩阵与样本元数据。
