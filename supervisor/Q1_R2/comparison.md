## 已观察但当前不改部署引擎的缺陷

- 恢复事件写在 session_meta 之前，日志不是完全规范的首行元数据顺序；监督端保留并标记 noncanonical_metadata_order，不重排原始日志。
- 3CA JSON 输出只按字符裁剪可能破坏结构且没有明确分页；上下文缩减仅按消息数量保留近期消息，不保证总长度和重要研究决策被保留。尚未将这些风险的猜测冒充已确证的最终失败原因。
- 最近仍重复相同 3CA category 搜索，护栏只提示“不重复”，不等于模型已经能自行选择下一行动。运行继续交由冻结的自身 loop；不通过人工指出某个数据集掩盖该不足。
- 回归测试此前跨任务遍历 JSON 而出现读取失败，已只修独立测试/监督定位，未改运行代理；修正后回归重跑通过。当前部署以 frozen-workflow-attempt3 中的运行代码为准，测试修正不作为模型执行中升级。
