# Research Quality

For the original dataset reference, call `verify_doi` with the stable `3ca:ID` directly (publisher DOI URLs are also accepted). It resolves only the catalog publication anchor and verifies exact Crossref metadata; never repeatedly guess a journal/title through unrelated generic search results. `get_study` returns the explicit verification call and the publication URL, and the checkpoint retains them.

Write methods from `core_result.methods`, not an assumed Scanpy default. State the exact `core_result.parameters.seeds`; do not invent a familiar seed grid. Preserve `zero_center=False` when that is the recorded feature scaling. HVG here means highest log-normalized expression variance, not Seurat-v3 dispersion normalization. Use `summary.baseline_silhouette_summary` to report the HVG comparator as well as random controls, even when HVG is stronger than metabolic features. Use `random_control_comparison` for the observed count and total: its add-one rank fraction is not the observed exceedance percentage and not a biological P value. Do not turn it into significance, generic better/worse/similar-to-random language or a conclusion that random controls prove robustness or its absence; do not describe NMI as causal or apply invented strong/moderate/weak thresholds; do not directly compare Leiden and KMeans silhouettes as if they test the same claim. Gene-draw seeds, embedding/KMeans seeds and the metric-only sampling seed are separately recorded. Prefer the saved vector PDF figures with category legends and explicit HVG/R01... labels; do not replace them with invented displays.

Source feature rows and unique gene symbols are different counts. The core sums exact duplicate symbols in raw counts before QC/normalization, preserves all original input files, and saves `source_feature_to_symbol.csv`. Report this symbol-level aggregation and its unresolved gene-ID/locus ambiguity; do not drop duplicates, add name suffixes, or claim stable gene IDs were verified. Manifest `dataset.n_genes` remains the original matrix feature-row count, not the aggregated symbol count.

Use `inspect_research_table` before interpreting any row count or joining a score table. Establish the table grain and a unique cell key; a long cell-by-program table is not a cell matrix. Use the prompt-supplied gene set when one exists; call `fetch_reactome_metabolic_genes` only when Reactome is requested or no set is supplied. CSV/TSV inputs must have a `symbol` column. Preserve the original file and report exact matches, unique case-insensitive matches, unmatched symbols and ambiguous mappings from `gene_set_mapping.csv`; never silently uppercase the source list. A program score column is not a metabolic gene-expression matrix.

After `download_asset(extract=true)`, call `prepare_3ca_dataset` with its actual `extracted_path`. It copies and hashes the raw-count matrix, Cells, Genes and optional Samples into `inputs`, verifies dimensions/keys, and returns exact workspace-relative paths for the core analysis. Do not guess archive folder names or use PowerShell copies. A TPM-only source is explicitly rejected; record why and choose a different raw-count study, not another spelling of the same input. Staging does not overwrite different previously staged files.

Keep matrices sparse. Verify orientation, cell/gene identifiers, dimensions, uniqueness, and metadata alignment before normalization. Call `analyze_metabolic_states` first without a subset for the global question. If the task asks about one cell type, inspect the metadata and call it again with the exact observed `subset_field`, `subset_values`, and a separate `output_dir`; never derive the subset from the new metabolic clusters. It retains every QC-passing selected cell, uses Scanpy/Leiden in matched metabolic-gene space, compares seeds/resolutions, runs a size-matched HVG control plus seeded random-gene controls, measures confounders, reports cell-type association globally and within biological replicates, and performs descriptive within-replicate reclustering. It saves true labels, figures, a summary, and a hashed core result. The metric-only subsample is shared across comparisons and does not alter the clustering population.

This core tool is exploratory: it does not test discrete biological states against a continuum and must not claim their existence or absence. Report whether metabolic genes separate observed cell groups separately from whether those groups are biological metabolic states. Copy the actual cluster-size range, resolution-selection filter/criterion, categorical NMI values, within-replicate global-vs-within ARI range and weakest replicate from the explicit summary fields. Do not test data-derived cluster labels on the same expression matrix; benchmark exceedance is not a biological P value, seed stability is conditional on the fixed preprocessing/graph, and a low confounder NMI does not prove independence. Do not infer that no cluster is patient/sample-dominated from aggregate NMI. Additional defensible independent-donor validation or a suitable null-model analysis may inform a separate conclusion without overwriting the core outputs.

Call `audit_analysis_code` before running any additional Python analysis. It combines Ruff undefined-name checks with guards against known invalid sparse-matrix, label, stability, QC, gene-fallback, and warning-suppression patterns. Cell-level tests do not create biological replicates; use replicate-aware summaries or pseudobulk for any additional inferential claim.

Use `search_pubmed` for discovery and `verify_doi` for every cited DOI; cite only fields present in saved metadata. A local workflow-design PDF does not supply a DOI, title, year, or journal unless its own verified metadata record exists. Build `results/analysis_manifest.json` from the global `core_result.json`, not from memory, and record any subset core path/hash as supporting analysis. Put every `includegraphics` inside the LaTeX document environment. After the final TeX edit, call `build_research_report`; after any repair call it again, then call `validate_research_bundle`. Research `complete_task` must cite that final validator's `verification_call_id`. Passing this deterministic gate does not prove the biological conclusion; state limitations and unsupported claims explicitly.

## Illustrated report and layout contract

Make the report visually explanatory, not a text dump. Load `graphicx`, `booktabs`, `amsmath`, and `url` in the preamble. Include at least the two core vector PDF figures, each in its own `figure` environment with a factual caption, unique label, and an explicit prose `ref` that explains what the panel supports and what it cannot establish. Never place `includegraphics` in the preamble.

Include at least one publication-style three-line table using `booktabs`, `toprule`, `midrule`, and `bottomrule`, with no vertical rules. Give the table a caption and label, cite it in prose, state units/analysis population, and source every value from saved results. Prefer compact tables for primary metrics, controls, confounders, and replicate sensitivity over long prose lists.

Include at least one displayed, labeled, prose-referenced mathematical formula that is genuinely used in the analysis, such as the library-size/log normalization. Typeset log1p as the mathematically equivalent standard form `\\log(1+x)`, not `\\log_1p`. Define every symbol in a `where` sentence and do not add decorative mathematics or formulas for methods that were not run.

Compile the final TeX with the actual engine at least twice after the last content change. Keep the current `.log`; resolve compilation errors, undefined citations/references, and overfull boxes rather than suppressing them. A build failure returns the first compiler diagnostic, nearby source, and likely earlier unescaped underscores; repair those concrete lines before rebuilding instead of rereading the full log. Run `validate_research_bundle` only after the final compile. It renders every PDF page through Poppler, checks page count, nonblank content and page-edge cropping, and reports counts for figures, three-line tables, formulas, PDF pages, and rendered pages. Treat automatic rendering as a floor; the supervisor must still visually inspect every rendered page for overlap, unreadable labels, poor whitespace, captions split from content, and inconsistent typography before scientific acceptance.
