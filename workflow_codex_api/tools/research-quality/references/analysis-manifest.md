# Analysis manifest contract

`dataset.n_genes` is the original input feature-row count, including duplicate symbols. The core separately records `facts.unique_gene_symbols`, `facts.duplicate_symbol_rows_aggregated`, and a hashed source-row-to-symbol mapping. Exact duplicate symbols are summed in raw counts before QC; disclose this symbol-level assumption rather than implying stable gene IDs were disambiguated.

`results/analysis_manifest.json` is evidence, not prose. Use schema version `1` and these fields:

Copy hashes, `cell_name`, seed arrays, cluster counts, metrics, and subgroup core hashes directly from the saved core results. Keep `analysis.baselines`, `analysis.methods`, and `analysis.subgroup_analyses` as the documented nested arrays; never replace them with flattened `method_*` fields. In the report, state that exact seed grid, preserve recorded scaling such as `zero_center=False`, and render log1p as `\\log(1+x)`.

Counts must describe the same analysis population. Matrix Market dimensions, cell-id uniqueness, gene rows, and the expression SHA-256 are checked against the declaration. The engine, current engine hash, core-result hash, input hash, summary/label/matched-gene hashes, and analyzed-cell counts are cross-checked. The matched gene list uses the original supplied spellings and must be a subset of the saved source list; `gene_set_mapping.csv` separately records the expression symbols actually used. Every labels file must contain exactly one row per analyzed cell and at least two distinct labels; methods and baselines need finite metrics and saved result files. Every cited key must have matching Crossref metadata. Figures must exist and be referenced by the current TeX; the PDF must be newer than the TeX. When the question asks for within-cell-type states, include `analysis.subgroup_analyses` using an exact observed metadata value and report its core result separately from the global result.

Populate these fields from the actual `core_result.json`, not the illustrative numbers above. `facts.metrics` contains the true method metrics; `facts.random_control_comparison` separates the observed exceedance count/total from the descriptive add-one rank fraction; and `parameters.seeds` contains the actual clustering seeds. The add-one value is neither the observed percentage of random controls nor a biological P value. The core summary deliberately leaves discrete biological metabolic states inconclusive; describe observed cell-group separation separately.

Use `core_result.methods` for factual preprocessing and algorithm descriptions and `facts.baseline_silhouette_summary` for the actual HVG/random comparison. Do not call the variance-ranked HVG baseline Seurat-v3, omit a stronger HVG result, or conflate gene-selection seeds with embedding/K-means and metric-only sampling seeds. The core saves vector PDF figures, category legends, UMAP coordinates and their hashes. Use the current saved figures rather than recreating a more favorable display. Verify the dataset publication with `verify_doi(doi="3ca:ID")`; the tool resolves the catalog citation anchor and verifies Crossref metadata, not a guessed title.

For report writing: answer global separation, cell-type association, and same-cell-type separation in distinct Question 1, Question 2, and Question 3 sections, each with an explicit descriptive, candidate, or inconclusive verdict. Distinguish counts of cells from counts of biological replicates; state QC exclusions and metric-only sampling; copy `cluster_size_summary`, `resolution_selection`, `categorical_confounder_nmi`, `cell_type_association_summary`, `random_control_comparison`, and `within_replicate_summary` from each relevant core result. Report the resolution stability filter, median-silhouette criterion and ARI tie-breaker; state the actual random-control count/total and identify the add-one correction; give the within-replicate ARI range and weakest replicate. Global cell-type NMI does not establish a metabolic state, and cell-level counts are not independent biological replicates. No automatic threshold proves independence, multimodality, mechanism, causality, or statistical significance. Include labeled/captioned/prose-referenced vector figures for both the global and requested subset analyses, a labeled/prose-referenced `booktabs` three-line table with no vertical rules, and a labeled/prose-referenced formula whose symbols are defined in a `where` clause. After the final TeX edit, call `build_research_report`, retain its current log, then validate with `validate_research_bundle`; validation renders every PDF page and rejects blank/cropped pages, layout errors and stale output. Each bibliographic field must come from saved metadata (omit unavailable fields rather than guessing). Do not call this protocol formally preregistered.
